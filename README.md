# makefun-post-x-promote

Entry for the make.fun bounty "post-x-promote-make-your-own-bounty-01": a single public X post that quotes make.fun's make-your-own-bounty post, with a photo of its own attached. The post's address lives in POST.json, and main.ts (Node 22, standard library only) copies POST.json into the output directory so the house can read the post and rank it by its replies, reposts and quotes.
